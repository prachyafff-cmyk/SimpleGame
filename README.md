# Tower Defense + Procedural Map

เกม Tower Defense ที่สุ่มแผนที่ใหม่ทุกครั้ง เขียนด้วย Python ไฟล์เดียว ใช้แค่ `tkinter` ที่มากับ Python ไม่ต้องติดตั้ง library เพิ่ม

พัฒนาโดย Mr.Prachya

## วิธีรัน

ต้องมี Python 3.8 ขึ้นไป แล้วรันคำสั่งนี้ในโฟลเดอร์โปรเจกต์:

```bash
python tower_defense.py
```

## เป้าหมาย

ศัตรูจะออกมาจากประตูมิติสีม่วงทางซ้าย แล้วเดินตามถนนไปที่ปราสาททางขวา
ให้วางป้อมข้างถนนเพื่อกำจัดศัตรูก่อนถึงปราสาท ถ้าศัตรูไปถึงปราสาท จะเสียชีวิต
ชีวิตหมดเมื่อไหร่ถือว่าแพ้ เกมไม่มีจุดจบ ลองดูว่ารอดได้ถึง Wave ไหน

## วิธีเล่น

1. เลือกป้อมจากแถบด้านขวา หรือกดปุ่ม `1`-`9`
2. คลิกบนพื้นหญ้าเพื่อสร้างป้อม (สร้างบนถนน น้ำ ต้นไม้ หรือหินไม่ได้)
3. กด `Space` เพื่อเริ่ม Wave
4. ฆ่าศัตรูเพื่อเก็บทอง แล้วเอาไปสร้างหรืออัปเกรดป้อม
5. คลิกที่ป้อมเพื่ออัปเกรด (สูงสุดเลเวล 4), ขาย, หรือเปลี่ยนเป้าหมาย

เคล็ดลับ:

- จบ Wave จะได้ทองโบนัส ถ้าเรียก Wave ถัดไปก่อนเวลา จะได้ทองเพิ่ม
- ขายป้อมก่อนเริ่ม Wave 1 ได้เงินคืนเต็มจำนวน หลังจากนั้นได้คืน 70%
- ชี้เมาส์ที่ปุ่มอัปเกรด จะเห็นค่าพลังที่จะเพิ่มขึ้นเป็นสีเขียว
- กล่อง "Wave ถัดไป" บอกล่วงหน้าว่าจะเจอศัตรูแบบไหน

## ปุ่มควบคุม

| ปุ่ม | ทำอะไร |
|---|---|
| คลิกซ้าย | สร้างป้อม / เลือกป้อม |
| คลิกขวา หรือ `Esc` | ยกเลิก |
| `1` - `9` | เลือกป้อม |
| `Space` | เริ่ม Wave ถัดไป |
| `U` | อัปเกรดป้อมที่เลือก |
| `S` | ขายป้อมที่เลือก |
| `T` | เปลี่ยนเป้าหมาย: หน้าสุด / ท้ายสุด / เลือดมาก / ใกล้สุด |
| `F` | ความเร็วเกม 1x / 2x / 3x |
| `A` | เปิด/ปิด Auto wave |
| `P` | หยุดชั่วคราว |
| `R` | เล่นใหม่บนแผนที่เดิม |
| `N` | สุ่มแผนที่ใหม่ |

## ศัตรู

| ศัตรู | เจอตั้งแต่ Wave | ความสามารถ |
|---|---|---|
| ทหาร | 1 | ศัตรูพื้นฐาน |
| นักวิ่ง | 2 | วิ่งเร็วมาก |
| ค้างคาว | 3 | บินตรงข้ามแผนที่โดยไม่เดินตามถนน |
| แตกตัว | 4 | ตายแล้วแตกเป็นตัวเล็ก 2 ตัว |
| รถถัง | 5 | มีเกราะลดดาเมจ |
| หมอ | 6 | รักษาเพื่อนที่อยู่รอบตัว |
| โล่ | 7 | มีโล่ดูดดาเมจ และโล่ฟื้นเองได้ |
| วิญญาณ | 8 | หายตัวเป็นช่วงๆ ระหว่างนั้นยิงไม่โดน |
| บอส | 10, 20, 30, ... | ตัวใหญ่ เลือดเยอะ เรียกลูกน้องออกมาเรื่อยๆ |

ทุก 5 Wave จะเป็น Wave ฝูง (ศัตรูแบบเดียวมาเยอะๆ) และทุก 10 Wave จะมีบอส

## แผนที่สุ่ม

ทุกแผนที่สร้างจากเลข Seed ที่แสดงอยู่บนแถบด้านบน ถนนจะคดเคี้ยวแบบสุ่ม
มีบ่อน้ำ ต้นไม้ และหินวางอยู่ ทำให้แต่ละเกมต้องวางแผนวางป้อมไม่เหมือนกัน
กด `R` เพื่อเล่นแผนที่เดิมซ้ำ หรือกด `N` เพื่อสุ่มแผนที่ใหม่
